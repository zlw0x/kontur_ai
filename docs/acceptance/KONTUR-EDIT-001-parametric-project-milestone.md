# KONTUR-EDIT-001: корпус, правки, проект и экспорт

Дата: 2026-11-18. Результат: **PASS для ближайшего milestone этапа 2**.
Основа: `zlw0x/kontur_ai`, `master`, исходный commit `5474305`.
Прогон выполнен локально; производственное развёртывание и коммерческий выпуск не выполнялись.

## Подтверждённый сценарий

Через браузер, существующие API очереди и реальный build123d:

1. Создан открытый корпус 120×80×40 мм, стенка 3 мм — версия 1.
2. Ширина изменена числом до 140 мм — версия 2.
3. Команда `длина 90` — версия 3.
4. Команда `увеличь глубину на 10` — версия 4.
5. Команда `добавь отверстие диаметром 6 x 0 y 0` — версия 5.
6. Страница перезагружена: сохранились размеры, отверстие и история 1–5.
7. Кнопками браузера скачаны STEP, STL и редактируемый CAD-IR.
8. Скачанные файлы повторно открыты независимым verifier: **valid=true**,
   габариты **140×90×50 мм**, **1 тело**, **1 сквозное отверстие**.

Каждая правка — `BUILD_CAD`, без повторного чтения изображения и без вызовов AI.
Восстановление, неуспешная геометрия, недопустимые команды, чужой доступ,
CSRF, устаревшая версия, конкурентные правки и повторная отправка проверены
автотестами. Неуспешная версия сохраняется в истории и не выдаётся как READY.

Проверен также исходный округлённый корпус из существующего CAD-корпуса:
три правки габаритов и третье монтажное отверстие сохраняют исходные операции.
Совпадающее с существующим отверстие отклоняется проверкой числа отверстий.
