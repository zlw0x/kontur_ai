# Geometry validation

Deterministic validation for trusted worker outputs:

- non-empty M3D;
- ISO-10303-21 STEP header;
- bounded ASCII or binary STL parsing;
- finite, non-degenerate triangles;
- closed two-manifold mesh and connected body count;
- measured bounding box;
- through-hole count derived from the genus of a closed, connected mesh.

No AI-generated executable code is accepted or run.
